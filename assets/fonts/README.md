# Local Fonts Directory

Pixelverse uses crisp retro monospace / geometric system font stacks combined with pixel-aligned uppercase typography so the website runs with zero external font latency and works completely offline.

If you wish to drop in custom `.woff2` pixel fonts (such as `PressStart2P.woff2` or `VT323.woff2`), place them in this directory and reference them in `css/variables.css`.
